Questions fréquentes

Où sont stockées mes données ?

Entièrement sur ton appareil (via SwiftData, chiffré par iOS). Rien n'est envoyé sur un serveur. Si tu actives iCloud, tes habitudes et tâches se synchronisent entre tes appareils Apple, chiffrées de bout en bout par Apple.

Comment connecter Apple Santé ?

Ouvre l'onglet Santé dans Verve et accepte les autorisations. Verve peut lire tes pas, distance, énergie, sommeil, fréquence cardiaque et VO₂ max, et écrire tes séances complétées. L'accès est optionnel : l'app fonctionne sans.

Comment désactiver la synchronisation iCloud ?

Réglages iOS → [ton nom] → iCloud → Verve.

Comment supprimer mes données ?

Désinstaller Verve efface toutes les données locales. Les données iCloud se suppriment dans Réglages → [ton nom] → iCloud → Gérer le stockage → Verve. Les données écrites dans Apple Santé se retirent depuis l'app Santé d'Apple.

L'app collecte-t-elle des données ?

Non. Aucune collecte, aucun traçage, aucune publicité. Voir la politique de confidentialité.
